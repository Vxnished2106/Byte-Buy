# 🛒 Byte and Buy - E-commerce

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

**Byte and Buy** es una plataforma de comercio electrónico moderna, rápida y segura orientada a la venta de componentes de hardware, software y artículos tecnológicos. Este proyecto cuenta con una arquitectura escalable, un diseño intuitivo centrado en la experiencia del usuario (UX) y un proceso de compra optimizado.


## 🛠️ Stack Tecnológico

El proyecto está construido bajo una arquitectura desacoplada (Frontend y Backend):

### Frontend
*   **Framework:** React.js 
*   **Estilos:** CSS
*   **Gestión de Estado:** Redux Toolkit / Context API

### Backend & Base de Datos
*   **Entorno de Ejecución:** NestJS
*   **Base de Datos:** MySQL
*   **Autenticación:** JSON Web Tokens (JWT)
